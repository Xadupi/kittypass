                Icônes des sites
                
        
        
                Seul le nom du site est demandé (https://site/favicon.ico), jamais l'adresse complète ni vos identifiants. Les adresses locales (192.168…, .local) ne sont jamais contactées.
          Si le site n'a pas de favicon.ico, KittyPass lit les icônes déclarées par sa page d'accueil, puis essaie le domaine parent.
                
        
                
          
          
        
                
        
                
      
                
    
                

    
                
      
                Cliquez sur un raccourci puis appuyez sur la nouvelle combinaison (Échap annule, Retour arrière
        retire le raccourci). Ces raccourcis fonctionnent dans la fenêtre de KittyPass ; le raccourci global se règle
        dans « Saisie auto ».
                
      
                
        
      
                
      
                
      
                
        
        
      
                
    
                

    
                
      
                
      
      
                Depuis n'importe quelle fenêtre, ouvre KittyPass sur le choix de l'entrée à taper. Sous Wayland,
        le bureau demande de confirmer le raccourci.

            Sans fichier clé

            Toute personne ou tout programme qui y accède pourra les lire. Supprimez-le dès qu'il n'est plus utile.
                  
          
                  
          
        
                  
        
                  
        
                  
        
                  
          
          
        
                  
      
                  

      
                  
        
                  
        
                  Un fichier clé s'ajoute au mot de passe maître : il faut les deux pour ouvrir le coffre.
          Le fichier n'est jamais envoyé au serveur. Sauvegardez-le : sans lui, le coffre est perdu. Les autres
          appareils devront le choisir au prochain déverrouillage.
                  
        
                  
          
          
        
                  
        
                  
          Aucun fichier choisi
          
          
        
                  
        
        
        
                  Le changement est enregistré seulement après l'accord du serveur (connexion nécessaire).
                  
        
                  
        
                  
          
          
        
                  
      
                  

      
                  
        
                  

        
                  
          
                  Verrouillage automatique
                  
          
                  
            
             min d'inactivité
            
          
                  
          
                  Sur cet appareil seulement. Le coffre se verrouille aussi à la fermeture de l'application.
                  
          
                  
        
                  

        
                  
          
                  Remplissage automatique
                  
          
                  
          
                  
          
                  Dans les applis et le navigateur, appuyez sur un champ d'identifiant : Android propose les
            entrées dont l'URL correspond au site, ou androidapp://nom.du.paquet pour une appli.
            KittyPass doit être ouvert et déverrouillé.
                  
        
                  

        
                  
          
                  Empreinte digitale
                  
          
                  
          
                  
            
            
                  
          
                  
          
                  
          
                  Le mot de passe maître est gardé dans le trousseau de votre session (KWallet / GNOME
            Keyring) et n'en sort qu'après une empreinte reconnue par le lecteur (fprintd).
                  
          
                  
          
                  
        
                  

        
                  
          
                  Mot de passe maître
                  
          
                  C'est aussi le mot de passe du compte. Le coffre est re-chiffré et les autres appareils sont
            déconnectés : ils demanderont le nouveau mot de passe à leur prochaine synchronisation.
                  
          
          
          
          
                  
          
                  
        
                  

        
                  
          
                  Double authentification (2FA)
                  
          
                  
          
                  
            
                  Scannez ce code avec votre application d'authentification, ou saisissez la clé à la main,
              puis entrez le code affiché.
                  
            
            
                  
            
                  
              
              
            
                  
          
                  
          
                  
            Codes de secours : notez-les maintenant, ils ne seront plus affichés.
            
                  Chacun sert une seule fois si vous perdez votre téléphone.
                  
            
                    
            
          
                    
          
                    
            
            
            
                    
          
                    
          
                    
            
            
          
                    
          
                    
        
                    

        
                    
          
                    Appareils connectés
                    
          
                      
          
                      
          
                      Un appareil déconnecté garde son coffre local ; il lui faudra le mot de passe (et la 2FA) pour se reconnecter.
                      
          
                      
        
                      

        
                      
          
                      Versions du coffre sur le serveur
                      
          
                      Le serveur garde les 50 dernières versions. « Récupérer » copie une version dans un nouveau
            groupe, sans rien écraser : vous reprenez ce qu'il faut puis supprimez le reste.
                      
          
                        
          
                        
          
                        
        
                        

        
                        
          
                        Administration du serveur
                        
          
                        Pour créer un compte, créez une invitation et transmettez le code à la personne. Dans KittyPass,
            elle choisit « Créer un compte », colle le code, puis son identifiant et son mot de passe : vous ne le
            connaissez jamais.
